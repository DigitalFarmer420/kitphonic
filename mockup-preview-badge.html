Kitphonic · Preview mode badge

A long press on a lesson tile in Grown-ups opens that lesson as a read-only preview — nothing is written to the child’s progress. While the preview is open, a visible Preview badge sits in the top-right so a parent can tell this is not the child’s session. Tapping the badge exits and returns to Grown-ups. Frames are real app screens with the badge injected; look, feel and theme are unchanged.

1Placement

Top-right, just under the 64px top-bar buttons, right-aligned with the Help inset. Home, Help, the pebble path, and Kit stay clear. Gap is 0.75rem — 15px on this tablet, 12px on the phone — so both targets stay tap-safe.

2Colour

A soft sky pill, not a warning. Fill #EAF4FB, border #86BFE3 (sky), text #4E97C9 (sky dark). Distinct on cream #FFF8EC. No coral, no red.

3Size & exit

Height 2.75rem (44px at a 16px root; scales with the UI). Nunito ExtraBold 15px, 0.06em tracking — chrome, not a lesson word. The whole badge is the tap target; the × is a cue. Tap exits and writes nothing.

CSS to copy

/* Preview-mode badge. Mount on #stage while a grown-ups preview is open.
   The whole control is the exit target: tap to leave preview and return to
   Grown-ups. A preview never writes child progress, including on exit. */

#preview-badge,
.preview-badge {
  position: absolute;
  /* Top-right, just under the 64px top-bar buttons, so it never covers
     Home, Help / Say-it-again, the pebble path, or Kit (Kit sits on the left). */
  top: calc(0.875rem + clamp(64px, 4.5rem, 9rem) + 0.75rem);
  right: 1.125rem;
  z-index: 20;
  display: inline-flex;
  align-items: center;
  gap: 0.4rem;
  box-sizing: border-box;
  height: 2.75rem;          /* 44px at a 16px root — app minimum tap target */
  min-width: 2.75rem;
  padding: 0 0.35rem 0 0.95rem;
  border: 0.125rem solid var(--sky, #86BFE3);
  border-radius: 999px;
  background: #EAF4FB;      /* same soft-sky fill as digraph tiles */
  color: var(--skyd, #4E97C9);
  box-shadow: 0 0.1875rem 0 rgba(78, 151, 201, 0.22);
  font-family: Nunito, system-ui, sans-serif; /* chrome font, not Andika */
  font-weight: 800;
  font-size: 0.9375rem;     /* 15px */
  letter-spacing: 0.06em;
  line-height: 1;
  cursor: pointer;
  -webkit-tap-highlight-color: transparent;
}
#preview-badge:focus-visible,
.preview-badge:focus-visible {
  outline: 4px solid var(--skyd, #4E97C9);
  outline-offset: 3px;
}
.preview-badge-label { padding-bottom: 0.05rem; }
.preview-badge-x {
  display: flex;
  align-items: center;
  justify-content: center;
  width: 1.75rem;
  height: 1.75rem;
  border-radius: 50%;
  background: #fff;
  color: var(--skyd, #4E97C9);
  font-size: 1.25rem;
  font-weight: 700;
  line-height: 1;
}

/* Match existing top-bar insets on portrait and short landscape. */
.portrait #preview-badge,
.portrait .preview-badge { right: 0.875rem; }
.short #preview-badge,
.short .preview-badge {
  top: calc(0.625rem + clamp(64px, 4.5rem, 9rem) + 0.5rem);
  right: 1rem;
}
.tall #preview-badge,
.tall .preview-badge { right: 1.125rem; }
